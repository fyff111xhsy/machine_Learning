# Machine Learning Practice Repository

## 📌 项目简介

本仓库用于记录机器学习基础学习过程，包含经典算法的理论整理与代码实现。

内容以“理解算法本质”为核心目标，覆盖传统机器学习方法的推导、实现与实验验证。

适用于：

- 机器学习基础学习与复习
- 复试准备
- 算法理解与工程实现能力训练

---

## 🎯 学习目标

- 掌握经典机器学习算法的基本原理与数学结构
- 理解模型训练过程中的损失函数与优化逻辑
- 能够使用 Python 独立实现基础机器学习算法
- 具备对模型结果进行简单实验分析的能力

---

## 📂 项目结构

- codes 代码
- notes 理论笔记
- experiments 实验结果与分析
- README.md 项目说明
